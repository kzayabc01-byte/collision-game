# 玩家跟随镜头

镜头保留现有俯视角度和 38.5 的正交尺寸，不跟随车头旋转、不随速度缩放。普通移动采用与帧率无关的指数平滑（follow_speed=8）；视线中心对准玩家上方 0.8 单位，车身保持在中央附近。出生、换车、重生或瞬移超过 12 单位时立即重定位。暂停和结算时停止跟随。

取消以竞技场边界限制镜头的位置，避免靠墙时镜头停止、小车继续走到 UI 下方。原地图碰撞范围、墙、模型、建筑、场景布置与 UI 均保留。

GroundVisual 下增加 OuterBackdrop（512 × 512，纯视觉，无碰撞）。它共享原地面材质，UV 按原 124 × 98 地面继续延展，保留原有色彩、笔触尺寸和镜像延展方式。位于原地面下 0.025 单位，避免重叠闪烁。未修改原地面材质或 shader。

镜头跟随先使用无震动的基准位置计算，再叠加原有碰撞震动，防止震动被跟随抵消或造成中心漂移。镜头在 HUD 投影之前更新，玩家指示牌跟随当前画面。
