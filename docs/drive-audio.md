# 加速与行驶音效

正常运行 `play.cmd` 即可体验。三种车各自有一个独立的循环行驶音，声音由真实速度驱动；更快时，节奏和音调更高。松油门后仍有较轻的滑行声，完全停车后约 0.3 秒淡出。

| 车型 | 行驶声音 |
| --- | --- |
| 小马 | 带轻木响的车轮滚动 |
| 南瓜 | 低沉、有空腔感的车轴转动 |
| 史莱姆 | 低速为小脚步声，进入滚动后为连续胶体滚动声 |

史莱姆沿用玩法里的滚动状态：超过 4 进入滚动、低于 4 回到走路、正好 4 保持上一状态。倒车也有行驶声；原地顶住障碍时不会仅因为按着油门就持续升调。

连续音先只播放玩家自己的车辆，避免 AI 声音混在一起遮盖碰撞与拾糖。碰撞音和拾糖音仍使用独立播放器。行驶音与现有 SFX 总线相连，设置中的音效音量滑块可以控制。

## 修改入口

- `scenes/car.tscn` → `Feedback/DriveLoop`：连续行驶音播放器，`volume_db` 是满速给油时的最大音量，默认 -18 dB。
- `Feedback` 的 `drive_loops`：依次指定小马、南瓜、史莱姆的循环素材；`slime_step_sound` 指定脚步素材。
- `Feedback/MovementSound`：史莱姆脚步及走路/滚动切换短音。
- `scripts/car_feedback.gd` → `locomotion()`：速度、油门与音量、音调的对应关系。音量缓入约 0.12 秒、收弱约 0.06 秒；音调平滑变化，循环不会每帧重新开始。
- `assets/audio/drive/`：三个 2 秒循环 WAV 以及一个短脚步 WAV；循环素材导入设置为 Forward，PCM 保存。
- `art_source/build_drive_audio.py`：离线合成源文件，使用 NumPy。游戏只播放已保存的 WAV，后续可直接替换为正式录制音效。

停车淡出，击溃立即停止行驶音，重生从静音开始；暂停和重撞顿挫时跟随车辆暂停，退出场景释放播放器。此版沿用当前驾驶、碰撞和音乐系统。

## 验证

```powershell
# 逻辑验证
Godot --headless --path . --max-fps 60 --script res://tests/drive_audio.gd
# 真实混音输出与可选试听录制（不要用 Dummy 音频驱动）
Godot --path . --max-fps 60 --script res://tests/drive_audio.gd -- --output="C:/Temp/drive-audio"
```

测试覆盖三种循环、加速升调、松油门减弱、史莱姆阈值、音效并播、暂停恢复、停车、击溃、重生与 AI 静音。带窗口模式额外读取实际混音样本，验证声音确实输出。驾驶、角色规则及碰撞反馈测试也需保持通过。
