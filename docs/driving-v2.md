# 驾驶与AI V2设计记录

## 验收目标
1. 持续W后约1秒达到9；转向不切断油门。
2. 9速度持续漂移0.6秒后仍约7.2，能观察到15—35度侧滑。
3. 松Shift保持W和方向键也能弹射；最高9.45；反向键、碰撞和重生正确处理。
4. AI有糖箱时也能接战，无进展不永久追同一目标；支持绕柱、前方制动和倒车脱困。

## 驾驶规则
油门、方向盘、制动统一由sample_controls返回，玩家和AI共用车辆运动。相反油门先将有符号速度降至0，再开始反向行驶；A/D决定转向，倒车时横摆方向反转。低速提供55%转向率的原地辅助，避免完全停住时无法调头。
普通车转向率160度/秒，大质量适当降低。漂移转向倍率小车1.3、大车1.15；只使用每秒3的净减速，不再叠加旧82%转角损失。漂移进入3.5、退出2.5，方向松开容许0.22秒过渡。普通驾驶每90度保速85%（史莱姆92.5%），油门仍能补速。
车头独立保存，速度方向按抓地系数指数追随，漂移角最多40度。模型朝车头，碰撞仍按真实速度；玩家有黄色朝向三角标。

## 弹射
同向有效转向45度且持续0.18秒、尚有极速30%以上速度才就绪。保持W松Shift释放；倒车和无油门不释放。连续反向转向会清空资格。持续0.45秒、冷却0.8秒、前0.18秒转向70%；转向越大推力越弱，但不会完全关闭。奖励上限min(极速105%, max(极速, 出弯速度+车型补偿))，以免限制新的正常油门。
冷却中开始的漂移不能预存下一次奖励。撞击取消弹射；死亡、重生清状态；暂停与失焦取消准备。

## AI
按价值、距离、角色能力和当前目标保持加权选择。拾糖距离明确以实际距离衡量，小车26、大车18。附近危险可以立即打断。每条目标带身份与超时；无进展3秒，追击最长6秒，其他目标最长9秒，放弃后4秒不重选。
每0.65秒重建路径，实际读取墙与糖箱形状，按车体半径扩张，避免只用一条中心射线。目标糖箱允许直接冲撞，其余糖箱绕开。前方制动距离包含反应距离和停止距离。卡住1.2秒后短暂倒车转向再规划。重复路径历史每0.5秒采样，长时间无收获回到旧区域会放弃目标。
可读调试字段：intent、reason、target_key、target_changes、hunt_seconds、abandoned_targets、recoveries。当前仍是原型AI，目标切换和碰撞频率需要继续真人试玩调校；没有给AI额外属性。

AI对所有对手维护上次交手时间，长期未交手的对手逐渐获得选择权重，防止只在局部相互纠缠；不按玩家身份加属性或特殊优待。
