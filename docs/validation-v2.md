# V2 验证记录

环境：Godot 4.7.2，本机Windows；当前日期2026-11-03。

## 自动检查
基础55项、车型55项、回归71项、驾驶26项、AI行为9项，共216项通过。
驾驶包含真实带Shift修饰的W事件、面向下方相对转向、倒车转向、先停车再倒车、同时按反向键、持续转向加速、直线制动、漂移侧滑、继续转向时弹射、碰撞与重生、30/60/120Hz一致性。

实测：W持续1秒达到9；9速度漂移0.6秒后为7.20，车头与实际运动方向夹角32.06度；松Shift继续转向能加速。直线Shift半秒后约5，停止距离约5单位。

最终AI版本，两组随机种子：

| 种子 | 车对车接触 | 玩家接触 | 首次车对车接触 | 目标超时受控 | 车辆越界 |
|---|---:|---:|---:|---|---|
| 20261103 | 100 | 18 | 7.22秒 | 是 | 无 |
| 42 | 106 | 16 | 7.08秒 | 是 | 无 |

这两轮玩家不主动输入，AI主动找来；“接触”包括按原有接触冷却结算的碰撞，不等于每次都有糖果损失，也不代表所有随机局都能达到此频率。
另有一轮驾驶按键整局模拟完成，成功释放13次弹射，全部车辆在场内；该轮运行于最后一项AI目标分散调优之前，驾驶逻辑相同。
